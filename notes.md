# Git and GitHub Notes

## What is Git?

Git is a version control system used to track changes in files and projects.

## What is GitHub?

GitHub is an online platform where Git repositories are stored and shared.

## Common Git Commands

### Clone a Repository

```bash
git clone repository-url
```

### Check Status

```bash
git status
```

### Add Files

```bash
git add .
```

### Commit Changes

```bash
git commit -m "message"
```

### Push Changes

```bash
git push origin main
```
